# סיכום פרויקט כלי פיתוח (DevOps)

## מגישים: ירין בריו, אמנון ניסימוב, אופק יעקב.

## התבקשנו לבנות סביבת Web מלאה מבוססת קונטיינרים הכוללת מערכת ניהול תוכן (Drupal) ומסד נתונים. המטרה המרכזית הייתה לעבור מהקמה ידנית של התשתית לאוטומציה מלאה של תהליכי ההקמה, הגיבוי, השחזור והניקוי (מעין תהליך CI/CD בסיסי), ולנהל את כלל התוצרים במערכת ניהול גרסאות (Git).

## מה עשינו בפועל
* הקמנו סביבת Docker הכוללת רשת פנימית (`drupal-net`).
* הרמנו קונטיינר של מסד נתונים מסוג PostgreSQL וחיברנו אליו קונטיינר של אפליקציית Drupal.
* קינפגנו את האתר, הגדרנו משתמשי אדמין וצוות, והזנו תוכן בסיסי (מילון מושגים).
* ביצענו גיבוי מלא למסד הנתונים ולקבצי העיצוב (Volumes).
* ארזנו את כל הפעולות לתוך 4 סקריפטים (Bash) המבצעים את התהליך באופן אוטומטי.
* תיעדנו והעלינו את כל הקבצים ל-Repository הנוכחי.
* ## טכנולוגיות בהן השתמשנו
* **Docker** - לניהול והרצת הקונטיינרים (Containers, Networks, Volumes).
* **PostgreSQL** - מסד הנתונים הרלוציוני של האתר.
* **Drupal** - מערכת ניהול התוכן (CMS).
* **Bash** - שפת הסקריפטים (Shell Scripting) לאוטומציה של התהליכים בסביבת Linux.
* **Git & GitHub** - לניהול תצורה, שמירת גיבויים ושיתוף פעולה בצוות.

## מדריך למשתמש (Step-by-Step)
כדי להקים, לגבות ולנקות את סביבת האתר שלנו מאפס בסביבת Linux, יש לעקוב אחר השלבים הבאים:

### שלב 1: משיכת הפרויקט (Clone)
פתח את הטרמינל (Terminal) והרץ את הפקודה הבאה כדי למשוך את קבצי הפרויקט למכונה שלך:
`git clone <כאן_הכנס_את_הקישור_לריפוזיטורי_שלכם>`
לאחר מכן, היכנס לתיקיית הפרויקט:
`cd <שם_תיקיית_הפרויקט>`

### שלב 2: הקמת הסביבה והפעלת האתר
הרצת סקריפט ה-Setup תקים את רשת התקשורת ואת שני הקונטיינרים (האתר ומסד הנתונים). הרצת סקריפט ה-Restore ישלוף את הנתונים מה- DataBase.
הרץ בטרמינל:
`./setup.sh`
`./restore.sh`
*המתן מספר רגעים לעליית השירותים. כעת תוכל לגלוש לאתר דרך הדפדפן בכתובת: http://localhost:8080*

### שלב 3: גיבוי נתונים
כדי ליצור גיבוי של כל התוכן הקיים במסד הנתונים ולקבצי האתר, הרץ:
`./backup.sh`
(הסקריפט ייצור קובץ גיבוי וישמור את קבצי ה-Volumes).

### שלב 4: שחזור נתונים 
במידה והסביבה קרסה או שאתה מרים אותה על מכונה חדשה ורוצה לטעון את הגיבוי האחרון שנשמר, הרץ:
`./restore.sh`

### שלב 5: ניקוי הסביבה (Cleanup)
בסיום העבודה, חובה לנקות את הסביבה כדי לא לתפוס משאבים מיותרים. סקריפט הניקוי יעצור וימחק את הקונטיינרים, ימחק את תמונות ה-Docker וינקה את הרשתות וה-Volumes שיצרנו.
הרץ בטרמינל:
`./cleanup.sh`
